## Perubahan

| File | Perubahan |

Server menggunakan read-header timeout 5 detik dan idle timeout 60 detik.
Package domain `internal/` dibuat ketika pertama kali dibutuhkan sesuai arsitektur.
Runtime worker menjadi bagian BE-053.

## Menjalankan

Dari direktori `jawir-sentinel-be`, gunakan Go 1.24.4 atau lebih baru:

```bash
go mod download
go run ./cmd/api
```

Default port adalah `8080`. Untuk menggantinya:

```bash
APP_PORT=9090 go run ./cmd/api
```

`APP_PORT` harus berupa integer 1–65535; nilai kosong memakai default.
Konfigurasi dibaca dari environment process. File `.env` tidak dimuat otomatis.
Baseline ini dapat berjalan tanpa database, Firebase, atau Google Cloud credentials.

## Pengujian manual

Dengan API berjalan, kirim request berikut melalui REST Client atau API client pilihanmu:

```http
GET http://localhost:8080/health
```

Expected: **200 OK**, body kosong, tanpa token authentication.
Sesuaikan port jika menjalankan API dengan `APP_PORT` berbeda.
